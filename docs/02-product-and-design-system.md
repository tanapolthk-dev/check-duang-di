# 02 · แนวคิดผลิตภัณฑ์ Design System Sitemap และ User Flow

> เอกสารนี้เขียนก่อนเริ่มเขียนโค้ด และปรับให้ตรงกับสิ่งที่สร้างจริงหลังพัฒนาเสร็จ

## 1. แนวคิดผลิตภัณฑ์

**เช็คดวงดิ๊ (Check Duang Di<sup>CDD</sup>) โดย Vanij** — เว็บแอปเช็คดวงสั้น ๆ ที่กรอกวันเกิดแล้วได้ภาพรวม 5 หมวด กับกราฟจังหวะชีวิตแบบรอบ 12 ปี ภายในไม่กี่วินาที

หลักคิด 3 ข้อ
1. **จบเร็ว** — หน้าแรก → ฟอร์มสั้น → ผลลัพธ์ ไม่ต้องสมัคร
2. **โปร่งใส** — ทุกผลลัพธ์บอกว่ามาจาก "ปฏิทิน" "ความเชื่อ" หรือ "การจำลอง"
3. **ข้อมูลอยู่กับผู้ใช้** — ประมวลผลในเบราว์เซอร์ ไม่ส่งข้อมูลออกไปไหน

## 2. Design system

### ทิศทางภาพ: "ครามกับดาวเรือง"
สีครามจากผ้าย้อมครามไทย คู่กับสีดาวเรืองซึ่งเป็นดอกไม้มงคลที่คนไทยคุ้นตา ตั้งใจให้ต่างจากเว็บดูดวงทั่วไปที่ใช้ม่วงไล่เฉด หรือพื้นดำทอง

| โทเคน | ค่า (โหมดสว่าง) | ค่า (โหมดมืด) | ใช้กับ |
|---|---|---|---|
| `--ink` คราม | `#1F2B6B` | `#E8EBFA` | ข้อความหลัก โลโก้ |
| `--paper` กระดาษคราม | `#F4F6FC` | `#0F1536` | พื้นหลัง |
| `--surface` | `#FFFFFF` | `#18204A` | แผงผลลัพธ์ ฟอร์ม |
| `--marigold` ดาวเรือง | `#F4A81D` | `#F6B53A` | ปุ่มหลัก จุดเน้นบนกราฟ |
| `--jade` หยก | `#17785F` | `#4CC9A6` | ช่วงลมส่ง |
| `--lotus` บัว | `#B23A62` | `#F08AAB` | ช่วงชะลอ |
| `--muted` หมอก | `#555E86` | `#A9B0D6` | ข้อความรอง |
| `--focus` | `#1F2B6B` | `#F6B53A` | เส้นโฟกัส |

ความคมชัด: ข้อความหลักและรองผ่านเกณฑ์ WCAG AA (≥ 4.5:1) บนพื้นหลังของตัวเอง ปุ่มดาวเรืองใช้ตัวอักษรครามเข้ม ไม่ใช้ตัวอักษรขาวบนดาวเรือง (รายงานค่าที่วัดจริงอยู่ใน `05-test-plan-and-report.md`)

### ตัวอักษร
- ฟอนต์เดียว: **IBM Plex Sans Thai** (400/500/600/700) — โดย IBM ใบอนุญาต **SIL Open Font License 1.1** ได้มาจากแพ็กเกจ npm `@fontsource/ibm-plex-sans-thai` 5.3.0 และ **โฮสต์ไฟล์ฟอนต์เอง** ใน `assets/fonts/` (ไม่เรียก Google Fonts จึงไม่ส่ง IP ผู้ใช้ไปบุคคลที่สาม) สำเนาใบอนุญาตอยู่ที่ `assets/fonts/OFL-LICENSE.txt`
- สเกล (อัตราส่วน 1.25, ฐาน 17px เพราะอักษรไทยมีวรรณยุกต์ซ้อน): 14 / 17 / 21 / 27 / 34 / ตัวโชว์ 44–76 (clamp)
- ระยะบรรทัดเนื้อความ 1.7 หัวเรื่อง 1.25 ความยาวบรรทัดไม่เกินราว 70 ตัวอักษร

### โลโก้
- เครื่องหมาย: วงแหวน 12 ช่อง (สื่อรอบ 12 ปี) มีจุดดาวเรือง 1 จุดบอก "ตอนนี้"
- Wordmark ไทย: **เช็คดวงดิ๊** (ชื่อหลัก)
- Wordmark อังกฤษ: **Check Duang Di<sup>CDD</sup>** — CDD เป็นตัวยกด้วย `<sup>`
- ผู้ให้บริการ: "โดย Vanij"

### องค์ประกอบ
- ปุ่มหลัก: ทรงแคปซูล พื้นดาวเรือง ตัวอักษรคราม — มีแค่ปุ่มเดียวต่อหน้าจอ
- ปุ่มรอง: เส้นขอบคราม 1.5px พื้นโปร่ง
- ฟอร์ม: ป้ายอยู่บนช่อง ระบุ "(จำเป็น)" หรือ "(ไม่บังคับ)" มีคำอธิบายใต้ช่อง ข้อผิดพลาดแสดงใต้ช่องและสรุปด้านบน
- แผงผลลัพธ์: มุมโค้ง 18px ใช้เส้นขอบบาง ไม่ใช้เงา แต่ละหมวดมีแถบระดับ 5 ขั้น พร้อมป้ายที่มาของข้อมูล (ปฏิทิน / ความเชื่อ / จำลอง)
- กราฟ: SVG วาดเอง เส้นดาวเรืองบนแถบช่วงความไม่แน่นอนสีคราม จุด "ตอนนี้" และตารางข้อมูลสำรองสำหรับโปรแกรมอ่านหน้าจอ
- Focus: เส้นขอบ 3px สีครามเข้ม (โหมดสว่าง) หรือสีดาวเรือง (โหมดมืด) พร้อมรัศมีดาวเรืองอ่อน — เดิมใช้สีดาวเรืองทั้งสองโหมด แต่บนพื้นสว่างมีความคมชัดเพียง 1.86:1 จึงเปลี่ยน
- Motion: มีจังหวะเดียวคือวงแหวนบนหน้าแรกหมุนเข้าที่ตอนโหลด และปิดเมื่อผู้ใช้ตั้งค่า reduce motion

### เลย์เอาต์
```
เดสก์ท็อป (≥ 900px)                    มือถือ
┌──────────────────────────────┐        ┌───────────────┐
│ โลโก้          เมนู           │        │ โลโก้     เมนู │
├──────────────────────────────┤        ├───────────────┤
│ หัวเรื่องใหญ่ │   วงแหวน 12 ช่อง│        │  วงแหวน        │

│ [ เริ่มเช็คดวง ]               │        │ [เริ่มเช็คดวง]  │
├──────────────────────────────┤        │  3 ขั้นตอน      │
```

เนื้อหาจัดชิดซ้าย คอลัมน์อ่านกว้างสูงสุด 720px หน้าแรกบนเดสก์ท็อปแบ่ง 2 คอลัมน์

### ทบทวนแผนเทียบโจทย์
- เดิมคิดใช้พื้นครีมอุ่นกับตัวหนังสือเซอริฟ → เปลี่ยนเป็นพื้นขาวอมคราม เพราะครีม+เซอริฟเป็นค่าเริ่มต้นที่เห็นบ่อยและไม่เกี่ยวกับเรื่องดวงไทย
- เดิมคิดตั้งชื่อช่วงกราฟแบบสูง/กลาง/ต่ำ → เปลี่ยนเป็น "ลมส่ง / เก็บแรง / ชะลอ" ซึ่งไม่ทำให้ผู้ใช้กลัว และไม่ซ้ำคำของเว็บอ้างอิง
- ไม่ใช้การ์ดหน้าตาเหมือนกันทุกส่วน แผงผลลัพธ์กับขั้นตอนบนหน้าแรกใช้รูปแบบต่างกันตามลำดับชั้นข้อมูล

## 3. Sitemap
SPA หน้าเดียว ใช้ hash routing (โฮสต์บน static hosting ได้โดยไม่ต้องตั้งค่า rewrite)

```
#/            หน้าแรก — แนะนำบริการ + ปุ่มเริ่มเช็คดวง + 3 ขั้นตอน
#/check       แบบฟอร์มข้อมูลเกิด
#/result      ผลลัพธ์ — ภาพรวม ความรัก การงาน การเงิน จังหวะชีวิต + กราฟ + แชร์
#/how         หลักการทำงานและข้อจำกัด
#/privacy     ความเป็นส่วนตัวและการใช้ข้อมูล + ปุ่มลบข้อมูลที่จำไว้
#/open        เปิดบนมือถือ — คัดลอกลิงก์ + QR code (เมื่อมี URL เผยแพร่จริง)
(อื่น ๆ)       หน้าไม่พบ พร้อมลิงก์กลับหน้าแรก
```

## 4. User flow
```
หน้าแรก ──[เริ่มเช็คดวง]──▶ ฟอร์ม
                              │ กรอกวัน/เดือน/ปี พ.ศ. (จำเป็น)
                              │ เวลาเกิด หรือ ติ๊ก "ไม่ทราบเวลาเกิด"
                              │ ภูมิภาคที่เกิด (ไม่บังคับ)
                              │ [ ] จำข้อมูลบนเครื่องนี้ (ปิดไว้ก่อน)
                              ▼
                     ตรวจข้อมูล ──ผิด──▶ สรุปข้อผิดพลาด + โฟกัสช่องแรกที่ผิด
                              │ถูก
                              ▼
                     Loading (สถานะ "กำลังจัดเตรียมผล")
                              │
               ┌──────────────┴───────────────┐
             สำเร็จ                          ผิดพลาด
               ▼                               ▼
          ผลลัพธ์ ──▶ แชร์ข้อความแบบไม่ระบุตัวตน     Error state + [ลองอีกครั้ง]
               │      / เช็คใหม่ / อ่านหลักการ
               ▼
   เปิด #/result โดยไม่มีผล ──▶ Empty state + [กรอกวันเกิด]
```
กลับมาใช้งาน: ถ้าผู้ใช้ติ๊ก "จำข้อมูลบนเครื่องนี้" ฟอร์มจะเติมข้อมูลให้ครั้งหน้า (localStorage บนเครื่องผู้ใช้เท่านั้น) ลบได้ทุกเมื่อจากหน้าความเป็นส่วนตัว หรือปุ่ม "ลบข้อมูลที่จำไว้" บนฟอร์ม

## 5. หน้าจอหลัก
1. **หน้าแรก** — ชื่อแบรนด์ วงแหวน 12 ช่อง ประโยคบอกประโยชน์ ปุ่มเริ่ม คำยืนยันว่า "ฟรี ไม่ต้องสมัคร ข้อมูลไม่ออกจากเครื่อง" และ 3 ขั้นตอน
2. **ฟอร์ม** — 3 กลุ่มช่อง พร้อมเหตุผลว่าใช้ข้อมูลแต่ละช่องทำอะไร
3. **ผลลัพธ์** — สรุปพื้นฐาน (วันเกิดทางโหราศาสตร์ไทย ปีนักษัตร ราศี) → 5 หมวด → กราฟจังหวะชีวิต → แชร์ → ข้อจำกัด
4. **หลักการทำงาน** — ขั้นตอนประมวลผล สิ่งที่เป็นข้อเท็จจริง/ความเชื่อ/การจำลอง
5. **ความเป็นส่วนตัว** — ข้อมูลไปไหน เก็บที่ไหน ลบอย่างไร
6. **เปิดบนมือถือ** — ลิงก์ ปุ่มคัดลอก และ QR (แสดงเฉพาะเมื่อตั้งค่า URL จริงแล้ว)
