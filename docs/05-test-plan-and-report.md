# 05 · แผนทดสอบและรายงานผลการทดสอบ

วันที่ทดสอบ: 8 ตุลาคม 2569
สภาพแวดล้อม: Linux, Node.js 22.22.0, Python 3.13, Playwright 1.56 + Chromium 141.0.7390.37, เว็บเซิร์ฟเวอร์ภายในเครื่อง (127.0.0.1)
เวอร์ชันที่ทดสอบ: 0.1.0

> รายงานนี้บันทึกเฉพาะสิ่งที่รันจริง ผลอยู่ใต้ตารางแต่ละส่วน และข้อจำกัดอยู่ท้ายเอกสาร

## 1. วิธีรัน
```bash
npm test                     # unit tests (node:test)
npm run test:e2e             # end-to-end (Playwright + Chromium)
npm run check:secrets        # สแกน secret / ข้อมูลส่วนบุคคล
```

## 5. แผนทดสอบที่ยังต้องทำ (ยังไม่ได้รัน)
| รายการ | เหตุผลที่ยังไม่ได้ทำ |
|---|---|
| Safari (iOS/macOS), Firefox, Samsung Internet | สภาพแวดล้อมมีเฉพาะ Chromium |
| มือถือจริง Android/iOS และการสแกน QR ด้วยกล้อง | ยังไม่ได้ deploy และไม่มีอุปกรณ์จริง |
| โปรแกรมอ่านหน้าจอ NVDA, VoiceOver, TalkBack | ไม่มีในสภาพแวดล้อม |
| Lighthouse / axe-core | ยังไม่ได้ติดตั้งในชุดทดสอบ |
| ทดสอบความเข้าใจกับผู้ใช้จริงหลายวัย | ต้องจัดเซสชันกับผู้ใช้ |
| ตรวจ GitHub Actions workflow บน GitHub จริง | ยังไม่มี repository |

## 6. ข้อจำกัดของรายงาน
- ผลทั้งหมดมาจาก Chromium รุ่นเดียวในสภาพแวดล้อมพัฒนา
- "ไม่มีคำขอเครือข่ายภายนอก" วัดจาก event ของเบราว์เซอร์ระหว่างทดสอบ บนเว็บเซิร์ฟเวอร์ในเครื่อง
- ภาพหน้าจอจากการทดสอบอยู่ใน `tests/e2e/output/` (ไม่ถูก commit) และใช้ข้อมูลเกิดสมมติเท่านั้น
